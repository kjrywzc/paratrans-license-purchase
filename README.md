## 哪些坑要提前知道

数字商品交付后一般不退款，除非当地法律或该商品另有售后政策。这条不是数码荔枝独有的规则，但它是你下单前最该记住的一条。多数产品提供免费试用版，先下载跑一遍，确认功能和系统兼容性都符合预期，再付款。

买断、永久、终身更新这类措辞，信息来源是开发商，后续是否继续更新、政策怎么调整，由开发商决定，商城不承担补偿或退款责任。看到“永久”，理解成当前版本可以一直用，别理解成开发商承诺永远给你升级。

授权只限你自己使用。共享给同事、转售、出租、出借都违反协议，后果由使用方承担。想几个人分摊成本，正规做法是买对应人数的授权，而不是共用一份码。

激活码丢了，先联系开发商，再找商城协助。商城能帮你查订单、给指引，但码本身由开发商生成，指望商城凭空补一个新的并不现实。

系统要求、语言支持、和其他软件的兼容性，商品页会列出主要项，细节以开发商文档为准。买错版本这类问题基本走不了退款。
